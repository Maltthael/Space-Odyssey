# 🚀 Space Odyssey

A web application built with Django focused on user authentication, form validation, and dynamic rendering using templates.

---

## 🧠 About the Project

**Space Odyssey** is a web application developed using Django as part of my backend learning journey.  
The project demonstrates how to build a structured web system with user interaction, including registration, login, and form validation.

It follows Django’s architecture, separating logic, templates, and data handling into organized components.

## 📸 Features

- 🔐 User registration system
- 🔑 Login system
- ✅ Form validation with Django Forms
- 🔁 Password confirmation validation
- ⚠️ Error handling and feedback to the user
- 🎨 Styled interface using Bootstrap and custom CSS
- 🧩 Modular template structure (partials, reusable components)
