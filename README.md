# 🚀 Space Odyssey

A simple Django web application built for learning purposes.

---

## 🧠 About

This project was created to practice backend development using Django.  
It includes basic features like user registration, login, and form validation.

---

## ⚙️ Tech Stack

- Python  
- Django  
- HTML  
- CSS  
- Bootstrap  

---

## ✨ Features

- User registration  
- Login system  
- Password confirmation validation  
- Form validation using Django Forms  

---

## 🚀 How to Run

```bash
git clone https://github.com/Maltthael/Space-Odyssey.git
cd Space-Odyssey
pip install -r requirements.txt
python manage.py runserver
